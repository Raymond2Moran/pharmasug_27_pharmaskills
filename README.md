# pharmasug_27_pharmaskills

This is the repository for the development of pharma-related agent skills for PharmaSUG 2027 conference.

## Project development skill

[pharma-skills-development](.agents/skills/pharma-skills-development/SKILL.md) guides phased development of this project: standards retrieval, specification review, SDTM/ADaM programming, TLF generation, and independent QC.

Example invocation:

```text
Use $pharma-skills-development to implement Phase 0: create a reproducible
synthetic safety-study benchmark and explicit specifications for ADSL, ADAE,
a demographics table, and a TEAE summary. Identify unresolved analysis rules.
```

The skill includes a roadmap, implementation guidance, evaluation scenarios, and
a study-context template. Its package structure has been validated; clinical
programming behavior and end-to-end execution have not yet been evaluated.
It guides development of component skills; it does not contain implemented
SDTM/ADaM generators or a validated production programming system.
